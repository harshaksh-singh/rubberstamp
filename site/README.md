# RubberStamp site

The project site at https://harshaksh-singh.github.io/rubberstamp/.

- Astro 7 (static output), Tailwind CSS 4, GSAP 3 (ScrollTrigger, SplitText, Flip), self-hosted Geist fonts.
- Every result and chart comes from `src/data/site.json`, generated by `../scripts/site_data.py` from the committed
  results, the task suite and the training config.
- The site's charts are HTML tables drawn at build time in `src/pages/index.astro`, so they reflow on phones and
  screen readers read every value. `npm run charts` writes the README images (SVG, light and dark) to
  `../docs/assets/` with the scales and helpers in `src/lib/charts.ts`.
- `src/pages/og.png.ts` renders the social preview card at build time (satori + resvg). After changing it, copy
  `dist/og.png` to `../docs/assets/social-preview.png`, the image uploaded as the repository's social preview.
- Elements that animate in are hidden before first paint by an `anim` class that the inline script in
  `src/layouts/Base.astro` sets only when JS runs and motion is allowed; `src/scripts/site.ts` removes it once GSAP has
  set their start state (and a 4 s fallback removes it if the script never runs).

```bash
npm ci
npm run dev        # http://localhost:4321/rubberstamp/
npm run check      # astro check (TypeScript)
npm run build      # dist/
npm run charts     # README images
```

Deployed by `.github/workflows/site.yml` on every push to `main`.
