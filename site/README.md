# RubberStamp site

The project site at https://harshaksh-singh.github.io/rubberstamp/.

- Astro 7 (static output), Tailwind CSS 4, GSAP 3 (ScrollTrigger, SplitText, Flip), self-hosted Geist fonts.
- Every number comes from `src/data/site.json`, generated by `../scripts/site_data.py` from the committed results.
- Charts are SVG strings drawn at build time by `src/lib/charts.ts`; `npm run charts` writes the README images to
  `../docs/assets/` from the same code.
- `src/pages/og.png.ts` renders the social preview card at build time (satori + resvg).

```bash
npm ci
npm run dev        # http://localhost:4321/rubberstamp/
npm run check      # astro check (TypeScript)
npm run build      # dist/
npm run charts     # README images
```

Deployed by `.github/workflows/site.yml` on every push to `main`.
